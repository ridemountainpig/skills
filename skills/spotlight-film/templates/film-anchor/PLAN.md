# Formwright — anchor/beam style test

**Subject:** Formwright a fictional open-source form builder for agents. It has no
physical product, so it is the test case for both anchor modes:
`film.html?anchor=object` (a paper form card as a CSS 3D slab) and `?anchor=light`
(a spotlight hot core). UI states are authored for a style test.
**Duration:** 71.7 s (51.2 shot-seconds × pace 1.4, see the `runFilm` call in shots.js), 24 fps, 120 bpm. **Reference:** the 12 key frames and the motion
vocabulary in `references/key-frames.md`.
